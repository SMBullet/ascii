Observation

During the audit, it was found that the application performs no antivirus or malware scanning on uploaded files. A file containing the EICAR standard antivirus test signature (eicar.docx) was uploaded through the claims upload feature via a POST request to /apclp-webclaims-apis-v1-vrs/vblock, and was accepted, processed, and stored successfully with no detection or rejection. As EICAR is a universally-detectable test file that any antivirus engine is designed to flag, its successful upload confirms that no malware-scanning control exists on the upload path.

Recommendation

Implement server-side malware scanning on every file upload, scanning each file with an up-to-date antivirus/anti-malware engine before it is stored or made available, and rejecting or quarantining anything that fails. Uploads should be held in an isolated, non-executable staging area until scanning completes and stored outside the application's execution context, combined with strict file-type allowlisting, size limits, and logging and alerting on rejected files so malicious upload attempts are both blocked and traceable.
